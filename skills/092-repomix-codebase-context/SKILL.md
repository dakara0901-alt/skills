# Repomix Codebase Context

- **カテゴリ**: 開発生産性
- **参照元**: https://github.com/yamadashy/repomix

## 概要

大規模コードベース全体を1ファイルに圧縮・構造化し、Claudeに最適なコンテキストを提供。

## 提供価値

レガシー移行や大規模リファクタ時の文脈理解を劇的改善。開発生産性をスケール。

## 使いどころ

大規模コードベースを1ファイルに圧縮・構造化して、Claudeに最適な文脈を渡すために使う。
