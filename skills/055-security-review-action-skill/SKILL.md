# Security Review Action Skill

- **カテゴリ**: セキュリティ
- **参照元**: https://github.com/alirezarezvani/claude-skills/tree/main/engineering/skill-security-auditor

## 概要

GitHub PR差分を自動解析し、脆弱性・セキュリティリスクを検知・修正提案。

## 提供価値

DevSecOpsのコードレビューをAI化。リリース前セキュリティチェックを自動化。

## 使いどころ

GitHub PRの差分を解析して脆弱性やセキュリティリスクを検知・修正提案し、リリース前チェックを自動化するために使う。
