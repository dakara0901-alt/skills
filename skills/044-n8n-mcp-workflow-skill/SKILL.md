# n8n MCP Workflow Skill

- **カテゴリ**: PM・業務・HR・法務

## 概要

n8nノーコード自動化ツールをClaudeから直接呼出し、ワークフロー構築・実行・監視をMCPで一元管理。

## 提供価値

社内業務プロセス（請求・承認・通知等）をノーコードでAI連携。IT部門の負担を削減。
