# Data Journalism Skill

- **カテゴリ**: 財務・データ分析
- **参照元**: https://github.com/jamditis/claude-skills-journalism/tree/main/data-journalism

## 概要

データ取得・クリーニング・分析・可視化を一貫ワークフローで自動実行。

## 提供価値

経営分析・競合調査・レポート作成を高速化。データ駆動意思決定を推進。

## 使いどころ

複雑なデータを集計・分析して、ビジネスの意思決定に役立つレポートやグラフを自動で作るために使う。
