# Zero Trust Architecture Implementation Skill

- **カテゴリ**: セキュリティ

## 概要

マイクロセグメンテーションとIDベースアクセス制御をゼロトラスト原則で実装ガイド。

## 提供価値

内部脅威・横移動リスクを低減。NIST準拠のアーキ構築を加速。

## 使いどころ

ゼロトラスト原則でマイクロセグメンテーションやIDベースアクセス制御を実装して、横移動リスクを低減するために使う。
