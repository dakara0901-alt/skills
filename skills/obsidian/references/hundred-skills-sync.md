# 100スキル進捗 × Obsidian 同期

`hundred-skill-tracker` スキルが管理する `100-skills-progress.md` を、Obsidian の Vault で
使えるノート群に変換する仕組みの詳細。

## 役割分担（ここを取り違えないこと）

| 担当 | 責任 |
|---|---|
| `hundred-skill-tracker` | ユーザーの完了報告を `100-skills-progress.md` に記録する（**進捗の正**） |
| このスキルの同期スクリプト | progress.md を**読むだけ**で Obsidian のノートを生成・更新する |
| ユーザー | Obsidian 側のノートに学びメモを書き足す |

Obsidian 側のチェックボックスを手で `[x]` にしても progress.md には反映されない。
ユーザーが Obsidian で完了にしたと言った場合は、hundred-skill-tracker で progress.md を
更新してから、あらためて同期を走らせる。

## 実行

```bash
python3 scripts/hundred_skills_to_obsidian.py <100-skills-progress.mdのパス> --vault "$VAULT"
```

| オプション | 説明 |
|---|---|
| `--folder NAME` | Vault 内の出力先フォルダ（既定: `100スキル`） |
| `--no-skill-notes` | 1スキル1ノートを作らず、ダッシュボードとフォルダノートだけにする（11ノート） |
| `--dry-run` | 書き込まず、作成／更新される件数だけ表示する |
| `--json` | 結果を JSON で返す（件数と全体進捗を報告に使う） |

初回は 111 ノート（ダッシュボード1 + フォルダ10 + スキル100）が一気に作られる。
Vault を散らかしたくないユーザーには `--no-skill-notes` を勧めるか、まず `--dry-run` を見せる。

## 生成されるノート

```
100スキル/
├── 100スキル ダッシュボード.md      … 全体像。ここから辿る
├── フォルダ/
│   ├── 01_AI活用・自動化.md          … 10フォルダぶん
│   └── …
└── スキル/
    ├── 01-01 プロンプトエンジニアリング（AIへの指示設計）.md
    └── …                              … 100スキルぶん
```

スキルノートのファイル名は `<フォルダ番号>-<スキル番号> <スキル名>`。番号を先頭に置くことで、
ファイル名順に並べるとリスト順になり、別フォルダの同名スキルとも衝突しない。
`/` などファイル名に使えない文字は全角に置き換わる（`Zapier/Make` → `Zapier／Make`）。

## フロントマター（Dataview 用）

スキルノートには次のプロパティが入る。**この5つはスクリプトが管理する**ので、
ユーザーが手で書き換えても次回の同期で progress.md の内容に戻る。

```yaml
type: 100スキル/スキル
スキル番号: 3
フォルダ: 01_AI活用・自動化
フォルダ番号: '01'
状態: 完了            # または 未完了
完了日: 2026-08-24     # 完了かつ日付があるときのみ
tags:
  - 100スキル
  - 100スキル/完了     # または 100スキル/未完了
```

ユーザーが独自に足したプロパティ（`難易度` や `参考リンク` など）は保持される。

これを使った Dataview の例:

````markdown
```dataview
TABLE 完了日, フォルダ
FROM "100スキル/スキル"
WHERE 状態 = "完了" AND 完了日 >= date(2026-08-01)
SORT 完了日 DESC
```
````

ダッシュボードには未完了一覧と完了履歴の Dataview クエリが最初から入っている。
Dataview プラグインが無くても、静的な表とリストが同じ情報を持っているので困らない。

## 何度でも安全に実行できる仕組み

各ノートの自動生成部分は次のマーカーで囲まれている。

```markdown
<!-- hundred-skills:begin 自動生成ここから（このブロックは同期のたびに上書きされます） -->
（進捗・リンク・表）
<!-- hundred-skills:end 自動生成ここまで。以下に自由にメモを書けます -->

## 学んだこと
ここに書いたメモは同期しても消えない
```

同期時に置き換わるのはこのブロックの中と、上に挙げた管理プロパティだけ。ブロックの外は
一切触らない。マーカーが見当たらないノート（ユーザーが消した場合など）は、既存の本文を残したまま
先頭にブロックを足す。内容に差分がないノートは書き込み自体を行わない（更新日時が動かない）。

スキルノートは初回作成時だけ `## 学んだこと` / `## 実際にやったこと` / `## 次に試すこと` の
見出しが入る。ここに実践記録を溜めていくのが、このノート群の本来の目的。

## 報告のしかた

同期後は、件数だけでなく学習状況を一言添える。`--json` の `overall` / `streak_days` /
`next_default` を使えば、hundred-skill-tracker のダッシュボードと同じ数字が出せる。

> 100スキル/ に同期しました（更新3件・変更なし108件）。全体 5/100（5%）、🔥3日連続。
> 次は [[01-04 RPA（定型作業の自動化スクリプト作成）]] です。

ユーザーが Obsidian をすぐ開けるように、`scripts/vault.py uri "100スキル ダッシュボード"` で
`obsidian://` リンクを出して渡してもよい。
