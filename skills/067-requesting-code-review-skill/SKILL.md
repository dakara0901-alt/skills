# Requesting Code Review Skill

- **カテゴリ**: 開発生産性
- **参照元**: https://github.com/obra/superpowers/tree/main/skills/requesting-code-review

## 概要

レビュー前にチェックリストを実行し、重大度別に問題を自動報告・ブロック。

## 提供価値

コード品質ゲートを自動化し、リリース前バグ混入を防止。

## 使いどころ

レビュー前にチェックリストを実行し重大度別に問題を報告して、コード品質ゲートを自動化するために使う。
