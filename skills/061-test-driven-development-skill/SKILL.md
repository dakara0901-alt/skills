# Test-Driven Development Skill

- **カテゴリ**: 開発生産性
- **参照元**: https://github.com/obra/superpowers/tree/main/skills/test-driven-development

## 概要

RED-GREEN-REFACTORサイクルを強制。テストを先に書き、失敗確認→最小実装→検証を反復。

## 提供価値

バグ発生を根本抑制。リリースサイクル短縮と保守コスト削減に直結。

## 使いどころ

テストを先に書くRED-GREEN-REFACTORサイクルを徹底して、バグを根本から抑制するために使う。
