# Kaizen Continuous Improvement Skill

- **カテゴリ**: PM・業務・HR・法務
- **参照元**: https://github.com/NeoLabHQ/context-engineering-kit/tree/master/plugins/kaizen/skills/kaizen

## 概要

プロセス・コード・業務フローを定期レビューし、改善提案を生成・優先順位付け。

## 提供価値

継続的改善文化をAIで支え、組織生産性を長期的に向上。

## 使いどころ

プロセスや業務フローを定期レビューして改善提案を生成し、継続的改善を進めるために使う。
