# Source Verification Skill

- **カテゴリ**: PM・業務・HR・法務

## 概要

SIFT法・逆画像検索で出典検証ワークフローを実行し、事実確認を自動化。

## 提供価値

市場調査・競合分析・提案資料の信頼性担保を強化。誤情報リスクを低減。

## 使いどころ

SIFT法・逆画像検索で出典検証を自動化して、資料の信頼性を担保するために使う。
