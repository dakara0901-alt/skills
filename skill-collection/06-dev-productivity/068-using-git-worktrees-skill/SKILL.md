# Using Git Worktrees Skill

- **カテゴリ**: 開発生産性
- **参照元**: https://github.com/obra/superpowers/tree/main/skills/using-git-worktrees

## 概要

新規ブランチごとに隔離ワークスペースを作成し、クリーンなテスト環境を自動構築。

## 提供価値

並行開発時の競合を排除し、安全に実験・統合が可能に。

## 使いどころ

ブランチごとに隔離したgit worktreeを作成して、並行開発の競合を排除し安全に実験するために使う。
