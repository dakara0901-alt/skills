# 📖 使い方（Obsidian連携）

この `obsidian-vault` フォルダは、そのまま **Obsidianの保管庫（Vault）** として開けます。

## 🚀 導入手順
1. Obsidianを起動 → **「保管庫を開く」→「フォルダを保管庫として開く」**
2. この `obsidian-vault` フォルダを選択
3. [[🏆 使える最高のスキル100]] を開く（ホーム／ダッシュボード）

## 🔌 おすすめプラグイン
- **Dataview** … [[🏆 使える最高のスキル100]] とカテゴリノートの進捗ダッシュボードを表示（実質必須）
- **Tasks / Templater** … 学習メモやタスク管理を強化（任意）

## 🏷 データ構造
- **プロパティ**: `番号` / `カテゴリ`（リンク）/ `状態` / `ツール` / `aliases`
- **タグ**: `#スキル100`（全体）, `#スキル100/<カテゴリ>`（分野別）, `#スキル100/MOC`（カテゴリ索引）
- **リンク**: 各スキルは「前後のスキル・カテゴリMOC・ホーム」に相互リンク

## ✅ 進捗の付け方
各スキルノート上部のプロパティ **状態** を編集：
`未着手` → `学習中` → `習得済`
→ [[🏆 使える最高のスキル100]] のダッシュボードに自動集計されます。

## 🔗 グラフビュー
グラフビューを開くと、ホーム→カテゴリ→スキルのつながりが可視化されます。
タグ `#スキル100/MOC` でカテゴリMOCだけを抽出することも可能です。

## 🔄 進捗を「自動同期」したい場合（公式 obsidian スキル）
このリポジトリには公式の **`obsidian` スキル**（`skills/obsidian`）があり、
`hundred-skill-tracker` が管理する学習進捗 `100-skills-progress.md` を、あなたの実際のVaultへ
何度でも安全に同期できます（管理ブロックだけ上書き・メモは保持）。

自分のPCで:
```bash
python3 skills/obsidian/scripts/hundred_skills_to_obsidian.py \
    <100-skills-progress.mdのパス> --vault "<あなたのVaultのパス>"
```

- このVault（`obsidian-vault`）= **参照用**（ツール・手順・リソースを読む）
- 公式スキルの同期 = **進捗用**（完了状況・ストリークを記録）

用途に応じて併用してください。
