# 92. タスク管理システム構築

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 92/100

## 📌 概要
信頼できるタスク管理の仕組みで、頭を空にして実行に集中する。

## 🌍 世界最高峰のツール・手法
- Todoist / TickTick
- Notion / Things
- GTD手法
- 週次レビュー

## 🛠 実践ステップ
1. すべてのタスクを一箇所に集約(収集)
2. プロジェクト/次の行動に分解
3. 優先度・期日・文脈で整理
4. 毎日/毎週レビューで更新
5. 実行に集中できる状態を保つ

## 📚 厳選リソース
- 『Getting Things Done』(David Allen)
- Todoist/Notion公式ガイド
- 『タスク管理の教科書』系
