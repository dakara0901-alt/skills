# 100. 意思決定フレームワーク活用

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 100/100

## 📌 概要
フレームワークで判断の質とスピードを高め、後悔を減らす。

## 🌍 世界最高峰のツール・手法
- 可逆/不可逆の判断
- メンタルモデル
- 10-10-10
- エイゼンハワー行列

## 🛠 実践ステップ
1. 決定の重要度と可逆性を見極める
2. 可逆な決定は速く、不可逆は慎重に
3. 複数のメンタルモデルで多面的に検討
4. 感情でなく基準で判断
5. 決定を記録し後で振り返る

## 📚 厳選リソース
- 『Thinking, Fast and Slow』(Kahneman)
- 『Poor Charlie's Almanack』(メンタルモデル)
- 『Decisive』(Chip & Dan Heath)
