`🚀 10_生産性・自己管理` ｜ `スキル 100 / 100`

## 🌍 世界最高峰のツール・手法
- 可逆/不可逆の判断
- メンタルモデル
- 10-10-10
- エイゼンハワー行列

## 🛠 実践ステップ
1. 決定の重要度と可逆性を見極める
2. 可逆な決定は速く、不可逆は慎重に
3. 複数のメンタルモデルで多面的に検討
4. 感情でなく基準で判断
5. 決定を記録し後で振り返る
