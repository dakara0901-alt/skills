# 91. タイムブロッキング

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 91/100

## 📌 概要
予定表に作業時間を確保し、重要業務を確実に前進させる。

## 🌍 世界最高峰のツール・手法
- Googleカレンダー / Motion
- ディープワーク枠
- テーマ別デイ
- バッファ確保

## 🛠 実践ステップ
1. 1日を作業ブロックに分割
2. 最重要業務を朝の集中枠へ
3. 会議/雑務をまとめてブロック化
4. 割り込み用バッファを確保
5. 終業前に翌日を計画
