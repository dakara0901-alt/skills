# 96. 目標設定・逆算思考

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 96/100

## 📌 概要
ゴールから逆算して計画し、着実に成果へ到達する。

## 🌍 世界最高峰のツール・手法
- OKR
- SMART目標
- マイルストーン分解
- 週次レビュー

## 🛠 実践ステップ
1. 最終目標を測定可能に定義(SMART/OKR)
2. ゴールからマイルストーンへ逆算
3. 週/日の行動に落とし込む
4. 進捗を定期レビュー
5. 状況に応じ軌道修正

## 📚 厳選リソース
- 『Measure What Matters』(John Doerr)
- 『7つの習慣』(終わりを思い描く)
- OKR実践ガイド
