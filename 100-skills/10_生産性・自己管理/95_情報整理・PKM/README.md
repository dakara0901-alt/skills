# 95. 情報整理・PKM

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 95/100

## 📌 概要
個人の知識を蓄積・接続し、いつでも引き出せる第二の脳を作る。

## 🌍 世界最高峰のツール・手法
- Obsidian / Notion / Logseq
- PARA / Zettelkasten
- デイリーノート
- タグ・リンク構造

## 🛠 実践ステップ
1. 情報を一箇所に集約するツールを固定
2. PARA(領域別)で整理
3. メモを相互リンクし知識を接続
4. 定期的に見直し・要約
5. アウトプットで知識を定着
