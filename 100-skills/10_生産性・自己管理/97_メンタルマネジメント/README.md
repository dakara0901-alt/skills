# 🚀 97. メンタルマネジメント

`🚀 10_生産性・自己管理` ｜ `スキル 97 / 100`

> ストレスと感情を管理し、持続可能に高いパフォーマンスを保つ。

<br>

## 🌍 世界最高峰のツール・手法
- 認知行動(CBT)の考え方
- マインドフルネス/瞑想
- ジャーナリング
- 睡眠・運動・栄養

## 🛠 実践ステップ
1. ストレス要因と反応を客観視
2. 認知の歪みを捉え直す
3. 瞑想・呼吸で自律神経を整える
4. ジャーナリングで感情を言語化
5. 睡眠/運動/栄養の土台を守る

## 📚 厳選リソース
- 『マインドフルネスストレス低減法』
- 『Feeling Good』(David Burns)
- Headspace / Calm
