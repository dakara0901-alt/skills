# 99. 人脈構築・ネットワーキング

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 99/100

## 📌 概要
ギブ先行で信頼関係を築き、機会と協力を引き寄せる。

## 🌍 世界最高峰のツール・手法
- ギブファースト
- 弱い紐帯の活用
- フォローアップの仕組み
- コミュニティ参加

## 🛠 実践ステップ
1. まず相手に価値を与える(ギブ先行)
2. 広く浅い『弱い紐帯』も大切に
3. 出会いを記録しフォローアップ
4. 定期的な近況共有で関係維持
5. コミュニティ/イベントで接点拡大

## 📚 厳選リソース
- 『Give and Take』(Adam Grant)
- 『Never Eat Alone』(Keith Ferrazzi)
- 『Superconnector』
