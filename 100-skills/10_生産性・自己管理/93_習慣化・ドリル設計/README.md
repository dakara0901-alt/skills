# 93. 習慣化・ドリル設計

> カテゴリ: ⏱️ 10_生産性・自己管理　｜　スキルNo. 93/100

## 📌 概要
行動を自動化する習慣を設計し、意志力に頼らず継続する。

## 🌍 世界最高峰のツール・手法
- 習慣の4法則(Atomic Habits)
- トリガー→行動→報酬
- 習慣トラッカー
- 2分ルール

## 🛠 実践ステップ
1. 既存習慣に新習慣を紐づける(積み重ね)
2. 行動のハードルを下げる(2分ルール)
3. トリガーと環境を設計
4. トラッカーで可視化・連続を狙う
5. 小さな成功を報酬で強化
