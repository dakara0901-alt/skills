# 69. トレンド予測・時系列分析

> カテゴリ: 📊 07_データ分析・リサーチ　｜　スキルNo. 69/100

## 📌 概要
過去データから傾向・季節性を読み、将来を予測する。

## 🌍 世界最高峰のツール・手法
- 移動平均/指数平滑
- ARIMA / Prophet
- 季節調整
- Googleトレンド

## 🛠 実践ステップ
1. データの傾向・季節性・周期を可視化
2. 移動平均でノイズを除去
3. Prophet等でモデル化・予測
4. 予測区間で不確実性を示す
5. 実績と比べ継続的に補正

- Meta Prophet公式
- 『時系列分析』(沖本竜義)
- Google Trends
