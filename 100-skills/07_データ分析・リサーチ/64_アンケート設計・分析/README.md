> カテゴリ: 📊 07_データ分析・リサーチ　｜　スキルNo. 64/100

## 📌 概要
偏りのないアンケートを設計し、示唆あるデータを得て分析する。

## 🌍 世界最高峰のツール・手法
- Google Forms / Typeform
- 質問設計(バイアス回避)
- 尺度(リッカート)
- クロス集計

## 🛠 実践ステップ
1. 調べたい仮説と指標を先に決める
2. 誘導/二重質問を避ける
3. 選択肢を網羅的・排他的に
4. サンプルの偏りに注意
5. クロス集計で示唆を抽出
