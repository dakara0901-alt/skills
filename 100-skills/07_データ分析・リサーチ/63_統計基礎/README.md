# 63. 統計基礎

> カテゴリ: 📊 07_データ分析・リサーチ　｜　スキルNo. 63/100

## 📌 概要
相関・分布・仮説検定などの基礎で、データから正しく判断する。

## 🌍 世界最高峰のツール・手法
- 記述統計/推測統計
- 相関≠因果
- 仮説検定・p値
- 信頼区間

## 🛠 実践ステップ
1. データの分布・外れ値を確認
2. 平均だけでなくばらつきを見る
3. 相関と因果を混同しない
4. 仮説検定で有意差を確認
5. 効果量・信頼区間で解釈
