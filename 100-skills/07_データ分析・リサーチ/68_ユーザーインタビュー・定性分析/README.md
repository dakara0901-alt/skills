# 68. ユーザーインタビュー・定性分析

> カテゴリ: 📊 07_データ分析・リサーチ　｜　スキルNo. 68/100

## 📌 概要
顧客の本音と行動を深掘りし、数字に出ない洞察を得る。

## 🌍 世界最高峰のツール・手法
- デプスインタビュー
- JTBD(片付けたい用事)
- 親和図法
- 質的コーディング

## 🛠 実践ステップ
1. 解決したい問いを定義
2. 誘導せず行動と理由を深掘り
3. 『なぜ』を繰り返し本質へ
4. 発言を付箋化しパターン抽出
5. インサイトを施策へ翻訳

## 📚 厳選リソース
- 『The Mom Test』(Rob Fitzpatrick)
- 『Interviewing Users』(Steve Portigal)
- JTBD解説(Clayton Christensen)
