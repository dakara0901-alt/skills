# 💻 53. データベース設計基礎

`💻 06_プログラミング・ノーコード開発` ｜ `スキル 53 / 100`

> データを正しく構造化し、拡張性と整合性のあるDBを設計する。

<br>

## 🌍 世界最高峰のツール・手法
- PostgreSQL / MySQL
- Supabase / Firebase
- 正規化・ER図
- インデックス設計

## 🛠 実践ステップ
1. 扱うデータと関係(ER図)を洗い出す
2. 正規化で冗長排除、必要に応じ非正規化
3. 主キー/外部キー/制約を設定
4. クエリに合わせインデックス設計
5. バックアップ・マイグレーション運用
