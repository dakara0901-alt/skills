# 51. Webサイト制作

> カテゴリ: 💻 06_プログラミング・ノーコード開発　｜　スキルNo. 51/100

## 📌 概要
HTML/CSSやノーコードで、目的を達成するWebサイトを制作・公開する。

## 🌍 世界最高峰のツール・手法
- HTML/CSS/JavaScript
- Framer / Webflow（ノーコード)
- Next.js / Astro
- Vercel / Netlify（公開)

## 🛠 実践ステップ
1. 目的とターゲットから構成を設計
2. レスポンシブ・アクセシビリティを担保
3. 高速表示(画像最適化等)を重視
4. フォーム/計測を組み込む
5. 独自ドメインで公開・運用
