# 55. ボット開発

> カテゴリ: 💻 06_プログラミング・ノーコード開発　｜　スキルNo. 55/100

## 📌 概要
Slack/Discord/LINE botで通知・自動応答・業務連携を実装する。

## 🌍 世界最高峰のツール・手法
- Slack Bolt / Discord.js
- LINE Messaging API
- Webhook
- サーバレス(Cloud Functions)

## 🛠 実践ステップ
1. 解決する業務(通知/応答/操作)を定義
2. 各プラットフォームのAPI/権限を設定
3. イベント受信→処理→応答を実装
4. 外部API/DBと連携
5. サーバレスで低コスト運用

- Slack API公式(Bolt)
- discord.js Guide
- LINE Developers公式
