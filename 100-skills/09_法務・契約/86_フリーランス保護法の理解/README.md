# ⚖️ 86. フリーランス保護法の理解

`⚖️ 09_法務・契約` ｜ `スキル 86 / 100`

> 取引の適正化を図る新法を理解し、自分の立場を守る。

<br>

## 🌍 世界最高峰のツール・手法
- 取引条件の明示義務
- 報酬支払期日
- 禁止行為(買いたたき等)
- 相談窓口

## 🛠 実践ステップ
1. 業務委託時の条件明示義務を把握
2. 報酬支払期日(60日以内等)を確認
3. 不当な減額/やり直し等の禁止を理解
4. ハラスメント防止措置を確認
5. トラブル時の相談窓口を把握
