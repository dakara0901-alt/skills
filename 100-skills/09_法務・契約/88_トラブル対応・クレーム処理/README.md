## 🌍 世界最高峰のツール・手法
- 初期対応(傾聴・謝罪)
- 事実確認・記録
- エスカレーション基準
- 再発防止

## 🛠 実践ステップ
1. まず傾聴し感情に寄り添う
2. 事実を確認し記録を残す
3. 対応方針を迅速に決定・提示
4. 解決後に再発防止策を講じる
5. 悪質案件は専門家/警察に相談
