# 84. 特商法・景表法の基礎

> カテゴリ: ⚖️ 09_法務・契約　｜　スキルNo. 84/100

## 📌 概要
広告表現の法規制を理解し、違反リスクを避ける。

## 🌍 世界最高峰のツール・手法
- 景品表示法(優良/有利誤認)
- 特定商取引法表記
- ステマ規制
- 医薬品等の表現規制

## 🛠 実践ステップ
1. 誇大・優良誤認表現を避ける
2. 根拠なき『No.1』『必ず』を使わない
3. 特商法の表記義務を満たす
4. ステマ規制(広告明示)に対応
5. 業界別規制(薬機法等)を確認
