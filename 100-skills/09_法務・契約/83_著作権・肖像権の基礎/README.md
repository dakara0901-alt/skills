# 83. 著作権・肖像権の基礎

> カテゴリ: ⚖️ 09_法務・契約　｜　スキルNo. 83/100

## 📌 概要
コンテンツ制作で侵害を避け、自分の権利も守る基礎知識。

## 🌍 世界最高峰のツール・手法
- 著作権の発生・範囲
- 引用の要件
- 肖像権・パブリシティ権
- ライセンス(CC等)

## 🛠 実践ステップ
1. 著作物は創作時に自動発生と理解
2. 引用は要件(主従/出典)を満たす
3. 人物写真は肖像権・同意を確認
4. 素材はライセンス条件を遵守
5. AI生成物の権利にも留意
