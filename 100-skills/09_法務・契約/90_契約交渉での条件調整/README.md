# 90. 契約交渉での条件調整

> カテゴリ: ⚖️ 09_法務・契約　｜　スキルNo. 90/100

## 📌 概要
契約条件を有利かつ公正に調整し、良好な関係で合意する。

## 🌍 世界最高峰のツール・手法
- リスク配分の交渉
- 代替案(BATNA)
- 優先順位づけ
- Win-Win設計

## 🛠 実践ステップ
1. 自社の譲れない点/譲れる点を整理
2. 相手の関心と制約を把握
3. リスク条項を交換で調整
4. 代替案(BATNA)を用意し臨む
5. 合意内容を正確に文書化
