# ⚖️ 82. NDA(秘密保持契約)チェック

`⚖️ 09_法務・契約` ｜ `スキル 82 / 100`

> 情報漏洩リスクから守るNDAの要点を確認できる。

<br>

## 🌍 世界最高峰のツール・手法
- 秘密情報の定義範囲
- 目的外使用禁止
- 有効期間・存続条項
- 一方/相互NDA

## 🛠 実践ステップ
1. 秘密情報の定義が広すぎ/狭すぎないか確認
2. 目的外使用・第三者開示の禁止を確認
3. 期間と契約後の存続を確認
4. 返還/破棄義務を確認
5. 不利な一方的条項に注意
