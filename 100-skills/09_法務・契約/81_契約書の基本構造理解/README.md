# 81. 契約書の基本構造理解

> カテゴリ: ⚖️ 09_法務・契約　｜　スキルNo. 81/100

## 📌 概要
契約書の型と主要条項を理解し、リスクを見抜く土台を作る。

## 🌍 世界最高峰のツール・手法
- 主要条項の理解
- 権利義務・責任分界
- AI契約レビュー(補助)
- 標準ひな形の活用

## 🛠 実践ステップ
1. 前文・定義・本文・一般条項の構造を把握
2. 対価・納期・責任・解除を精読
3. 賠償上限・秘密保持を確認
4. 不利/曖昧条項をマーキング
5. 重要案件は専門家確認
