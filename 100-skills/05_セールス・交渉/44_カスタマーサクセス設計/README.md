# 44. カスタマーサクセス設計

> カテゴリ: 🤝 05_セールス・交渉　｜　スキルNo. 44/100

## 📌 概要
顧客の成功を能動的に支援し、解約を防ぎLTVを最大化する。

## 🌍 世界最高峰のツール・手法
- オンボーディング設計
- ヘルススコア
- QBR(定期レビュー)
- チャーン分析

## 🛠 実践ステップ
1. 導入直後の成功体験(Aha)を設計
2. 利用状況でヘルススコアを可視化
3. 能動的にフォロー・提案
4. 解約予兆を検知し先回り
5. 成功事例を横展開・アップセル
