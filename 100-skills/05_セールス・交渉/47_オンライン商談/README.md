## 📌 概要
Zoom等の非対面で信頼を築き、画面共有と対話で意思決定へ導く。

## 🌍 世界最高峰のツール・手法

- 画面共有プレゼン

1. 事前にアジェンダとゴールを共有
2. カメラ・照明・音声環境を整える
3. 一方的説明でなく対話で進める
4. 画面共有で視覚的に価値提示
5. 要点と次アクションを即共有
