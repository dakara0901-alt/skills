# 41. 商談・クロージング

> カテゴリ: 🤝 05_セールス・交渉　｜　スキルNo. 41/100

## 📌 概要
顧客の課題を引き出し、価値提示から意思決定へ導いて成約する。

## 🌍 世界最高峰のツール・手法
- SPIN話法
- コンサルティングセールス
- BANT/MEDDIC(見極め)
- 反論処理

## 🛠 実践ステップ
1. ヒアリングで課題と理想を明確化
2. 課題の影響(コスト)を数値化
3. 価値をベネフィットで提示
4. 次のステップを常に合意
5. 沈黙を恐れず意思決定を促す
