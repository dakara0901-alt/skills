# 50. パートナーシップ構築

> カテゴリ: 🤝 05_セールス・交渉　｜　スキルNo. 50/100

## 📌 概要
他社・個人と協業し、互いの資産を掛け合わせて成長を加速する。

## 🌍 世界最高峰のツール・手法
- アライアンス設計
- Win-Win条件設計
- レベニューシェア
- 信頼構築(ギブ先行)

## 🛠 実践ステップ
1. 相互補完できる相手を見極める
2. 双方のメリットを明確に設計
3. 小さな協業から信頼を積む
4. 役割・収益分配を契約化
5. 定期見直しで関係を強化

## 📚 厳選リソース
- 『Give and Take』(Adam Grant)
- 『Never Eat Alone』
- アライアンス実務の解説記事
