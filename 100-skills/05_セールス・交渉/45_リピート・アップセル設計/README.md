# 45. リピート・アップセル設計

> カテゴリ: 🤝 05_セールス・交渉　｜　スキルNo. 45/100

## 📌 概要
既存顧客の再購入・単価向上を仕組み化し、収益基盤を安定させる。

## 🌍 世界最高峰のツール・手法
- LTV設計
- クロスセル/アップセル
- 会員/サブスク化
- RFM分析

## 🛠 実践ステップ
1. 初回購入後のフォロー体験を設計
2. 関連商品(クロスセル)を提案
3. 上位プラン(アップセル)への導線
4. 継続特典・会員制で離脱防止
5. RFMで優良顧客を厚くフォロー
