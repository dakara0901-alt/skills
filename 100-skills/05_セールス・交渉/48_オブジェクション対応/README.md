# 48. オブジェクション対応

> カテゴリ: 🤝 05_セールス・交渉　｜　スキルNo. 48/100

## 📌 概要
断り・懸念を歓迎し、傾聴と再提示で信頼を保ったまま前進させる。

## 🌍 世界最高峰のツール・手法
- 傾聴→共感→再提示の型
- LAER法
- 事前の反論想定
- 証拠での払拭

## 🛠 実践ステップ
1. 反論を歓迎し本音を引き出す
2. まず共感し否定しない
3. 懸念の真因を質問で特定
4. 証拠・事例で不安を払拭
5. 小さな合意を積み重ねる

## 📚 厳選リソース
- 『Objections』(Jeb Blount)
- 『Never Split the Difference』
- Sandler反論処理の解説
