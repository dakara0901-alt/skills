# 🤝 42. 価格交渉・値決め設計

`🤝 05_セールス・交渉` ｜ `スキル 42 / 100`

> 価値に基づく価格を設計し、値引きに頼らず利益を守る交渉をする。

<br>

## 🌍 世界最高峰のツール・手法
- 価値ベース価格設定
- アンカリング
- BATNA(代替案)準備
- 3段階プライシング

## 🛠 実践ステップ
1. 原価でなく提供価値から価格を設計
2. 松竹梅で意思決定を誘導
3. 最初の提示(アンカー)を高めに
4. 値引きは条件と交換で
5. BATNAを持ち強気に臨む
