# 78. 価格設定・原価計算

> カテゴリ: 💰 08_財務・会計・税務　｜　スキルNo. 78/100

## 📌 概要
原価を把握し、利益が残る価格を戦略的に設定する。

## 🌍 世界最高峰のツール・手法
- 原価計算(変動/固定費)
- 損益分岐点
- 値決め(価値ベース)
- 粗利率管理

## 🛠 実践ステップ
1. 変動費・固定費を分解し原価を把握
2. 損益分岐点(BEP)を計算
3. 価値ベースで価格上限を探る
4. 粗利率目標から下限を設定
5. 定期的に価格を見直す
