# 75. 見積書・請求書作成

> カテゴリ: 💰 08_財務・会計・税務　｜　スキルNo. 75/100

## 📌 概要
正確で信頼される見積・請求書を作り、入金までを管理する。

## 🌍 世界最高峰のツール・手法
- freee / マネーフォワード / Misoca
- インボイス制度対応
- 入金消込
- 支払条件明記

## 🛠 実践ステップ
1. 必要項目(登録番号/税率等)を網羅
2. インボイス要件を満たす
3. 支払期限・振込先を明記
4. 発行・送付・保存を電子化
5. 入金消込と督促を管理
