# 💰 80. 法人化・個人事業の選択

`💰 08_財務・会計・税務` ｜ `スキル 80 / 100`

> 税・社会保険・信用面から法人化のタイミングを判断する。

<br>

## 🌍 世界最高峰のツール・手法
- 所得の損益分岐(目安)
- 社会保険・役員報酬
- 信用・取引先要件
- 税理士相談

## 🛠 実践ステップ
1. 個人と法人の税負担を試算比較
2. 目安(利益)ラインで検討
3. 社会保険コストを織り込む
4. 信用・採用・取引要件も考慮
5. 税理士と最終判断
