# 💰 76. 資金調達基礎

`💰 08_財務・会計・税務` ｜ `スキル 76 / 100`

> 融資・出資・クラファン等の選択肢を理解し、必要資金を確保する。

<br>

## 🌍 世界最高峰のツール・手法
- 日本政策金融公庫(創業融資)
- 補助金・助成金
- クラウドファンディング
- エクイティ(VC/エンジェル)

## 🛠 実践ステップ
1. 必要額と使途を事業計画で明確化
2. 返済/非返済の資金性質を理解
3. 公庫/銀行融資の要件を把握
4. 補助金・クラファンも検討
5. 調達コストと希薄化を比較

- J-Net21(中小機構)
- 『起業のファイナンス』(磯崎哲也)
