# 74. 経費管理・領収書整理

> カテゴリ: 💰 08_財務・会計・税務　｜　スキルNo. 74/100

## 📌 概要
経費を正しく記録・保存し、節税と会計精度を両立する。

## 🌍 世界最高峰のツール・手法
- freee / マネーフォワード
- レシート撮影OCR
- 電子帳簿保存法対応
- 事業/家事按分

## 🛠 実践ステップ
1. 事業関連経費の区分を理解
2. レシートは即撮影・電子保存
3. 勘定科目を正しく仕訳
4. 家事按分を合理的基準で設定
5. 月次で締めて残高照合
