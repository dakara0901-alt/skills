# 71. 確定申告・青色申告

> カテゴリ: 💰 08_財務・会計・税務　｜　スキルNo. 71/100

## 📌 概要
個人事業主が正しく申告し、青色特典で節税する基礎知識。

## 🌍 世界最高峰のツール・手法
- freee / マネーフォワード / 弥生
- e-Tax
- 青色申告特別控除
- 電子帳簿保存

## 🛠 実践ステップ
1. 開業届・青色申告承認申請を提出
2. 会計ソフトで日々記帳
3. 経費区分を正しく仕訳
4. 控除(65万円等)を最大活用
5. e-Taxで期限内申告
