## 🌍 世界最高峰のツール・手法
- Hemingway Editor（冗長検出)

## 🛠 実践ステップ
1. まず構成(論理の流れ)を直す
2. 一文一義・能動態・短文化

4. 事実・数字・固有名詞を検証
5. 音読と時間を置いた再読で仕上げ
