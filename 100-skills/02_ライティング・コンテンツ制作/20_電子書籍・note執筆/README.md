# ✍️ 20. 電子書籍/note執筆

`✍️ 02_ライティング・コンテンツ制作` ｜ `スキル 20 / 100`

> 専門知識を体系化し、電子書籍やnoteで販売可能なコンテンツ資産にする。

<br>

## 🌍 世界最高峰のツール・手法
- Kindle Direct Publishing
- note / Zenn
- Scrivener / Ulysses（執筆)
- AIで構成＋人手で価値付け

## 🛠 実践ステップ
1. 読者の悩みと変化(before→after)を定義
2. 目次で価値の全体像を設計
3. 各章1テーマ・実践可能に
4. 無料部分で価値を証明し有料へ
5. レビュー・特典で信頼構築
