# 18. ストーリーテリング

> カテゴリ: ✍️ 02_ライティング・コンテンツ制作　｜　スキルNo. 18/100

## 📌 概要
ブランドや商品の物語を構築し、記憶と共感を通じてファンを作る。

## 🌍 世界最高峰のツール・手法
- ヒーローズジャーニー
- StoryBrand(顧客=主役)フレーム
- 3幕構成
- 感情曲線の設計

## 🛠 実践ステップ
1. 顧客を主役、ブランドを案内役に置く
2. 課題→変化→解決の変容を描く
3. 具体・五感・葛藤でリアリティを出す
4. 一貫したメッセージで反復
5. 各媒体へ物語を展開

## 📚 厳選リソース
- 『Building a StoryBrand』(Donald Miller)
- 『Story』(Robert McKee)
- Pixarのストーリールール
