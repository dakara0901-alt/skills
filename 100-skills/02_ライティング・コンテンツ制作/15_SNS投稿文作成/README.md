# 15. SNS投稿文作成

> カテゴリ: ✍️ 02_ライティング・コンテンツ制作　｜　スキルNo. 15/100

## 📌 概要
X/Instagram等でスクロールを止め、保存・シェアされる短文を書く。

## 🌍 世界最高峰のツール・手法
- フック1行目の型
- スワイプ/カルーセル構成
- Typefully / Buffer（作成・予約)
- トレンド・フォーマット活用

## 🛠 実践ステップ
1. 1行目で手を止めさせるフックを作る
2. 1投稿1アイデアで明快に
3. 改行・箇条書きで可読性を上げる
4. 保存/シェアされる実用価値を入れる
5. CTA(フォロー/リンク)で締める
