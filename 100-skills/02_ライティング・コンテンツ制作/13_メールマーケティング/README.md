# 13. メールマーケティング

> カテゴリ: ✍️ 02_ライティング・コンテンツ制作　｜　スキルNo. 13/100

## 📌 概要
リストへ価値を届けて関係構築し、開封・クリック・成約を高める文章と設計。

## 🌍 世界最高峰のツール・手法
- Klaviyo / Mailchimp / ConvertKit
- 件名A/Bテスト
- セグメント配信
- ステップメール(自動化)

## 🛠 実践ステップ
1. 件名で開封率、本文一つのCTAでクリック率を設計
2. セグメントで関連性を最大化
3. ウェルカム/カート放棄などシナリオ自動化
4. 配信時間・頻度を検証
5. 到達率(認証SPF/DKIM)を確保
