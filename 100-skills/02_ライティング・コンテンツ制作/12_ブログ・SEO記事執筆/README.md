# 12. ブログ/SEO記事執筆

> カテゴリ: ✍️ 02_ライティング・コンテンツ制作　｜　スキルNo. 12/100

## 📌 概要
検索意図を満たし上位表示される記事を書き、継続的な集客資産を作る。

## 🌍 世界最高峰のツール・手法
- Ahrefs / SEMrush（キーワード)
- Surfer SEO / Clearscope（最適化)
- Google Search Console
- Claude/GPTで下書き＋人手で品質担保

## 🛠 実践ステップ
1. 検索意図(情報/取引/案内)を分類
2. 上位記事を分析し不足トピックを補完
3. 結論先出し＋見出し構造(H2/H3)を設計
4. 一次情報・独自見解で差別化
5. 内部リンク・メタ・構造化データを整備

## 📚 厳選リソース
- Ahrefs Blog / Backlinko
- Google検索セントラル
- 『Everybody Writes』(Ann Handley)
