# 10. プロンプトライブラリ管理

> カテゴリ: 🤖 01_AI活用・自動化　｜　スキルNo. 10/100

## 📌 概要
再利用可能なプロンプトを資産として蓄積・バージョン管理し、チームで再現性を出す。

## 🌍 世界最高峰のツール・手法
- Notion / Obsidian（個人ライブラリ)
- LangSmith / PromptLayer（評価・履歴)
- Git（バージョン管理)
- PromptHub（共有・テンプレ)

## 🛠 実践ステップ
1. プロンプトを『目的×入力×出力』でメタ化
2. 変数化(プレースホルダ)して汎用テンプレに
3. 評価スコアと更新履歴を残す
4. タグ・カテゴリで検索可能に
5. チーム共有ルールを定める

## 📚 厳選リソース
- LangSmith公式ドキュメント
- Anthropic prompt library
- PromptLayer公式
