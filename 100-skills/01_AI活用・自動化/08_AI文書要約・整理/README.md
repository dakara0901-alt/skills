# 🤖 08. AI文書要約・整理

`🤖 01_AI活用・自動化` ｜ `スキル 8 / 100`

> 大量の文書・会議・論文をAIで要約し、意思決定に使える形へ構造化する。

<br>

## 🌍 世界最高峰のツール・手法
- Claude（長文200K+トークンに最適)
- NotebookLM（出典付き・音声要約)
- Notion AI（ドキュメント内要約)
- Perplexity（出典付きリサーチ要約)

## 🛠 実践ステップ
1. 入力を用途別に分類(議事録/論文/契約等)
2. 抽出したい項目をテンプレ化(結論/根拠/ToDo)
3. 長文はチャンク分割し階層要約
4. 出典・引用を必ず残す
5. 要約→アクション変換まで自動化
