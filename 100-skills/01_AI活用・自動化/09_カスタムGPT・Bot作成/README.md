# 🤖 09. カスタムGPT/Bot作成

`🤖 01_AI活用・自動化` ｜ `スキル 9 / 100`

> 特定業務に特化したチャットボットを作り、社内外の問い合わせを自動対応する。

<br>

## 🌍 世界最高峰のツール・手法
- OpenAI GPTs / Custom GPT
- Claude Projects（社内ナレッジ特化）
- Dify / Chatbase（RAG付きBot）
- Slack/LINE/Discord Bot連携

## 🛠 実践ステップ
1. 対象ユーザーとよくある質問を定義
2. ナレッジ(FAQ/ドキュメント)をRAGで接続
3. 口調・禁止事項をシステムプロンプトで規定
4. 逃げ道(有人切替)とログを用意
5. 利用データで継続改善
