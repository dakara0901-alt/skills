# 02. ノーコード自動化

> カテゴリ: 🤖 01_AI活用・自動化　｜　スキルNo. 2/100

## 📌 概要
コードを書かずにアプリ間のワークフローを自動化し、定型作業をゼロにする。

## 🌍 世界最高峰のツール・手法
- Make（旧Integromat・複雑分岐に強い/安価）
- Zapier（連携数No.1・最も安定）
- n8n（オープンソース・自己ホスト可）
- Pipedream（開発者向け・コード併用）

## 🛠 実践ステップ
1. 自動化したい定型作業を棚卸ししROIの高い順に並べる
2. トリガー→アクションの単純フローから作る
3. 分岐・フィルター・エラーハンドリングを追加
4. 実行ログを監視し失敗通知をSlack等へ
5. 月次でシナリオを見直し統廃合

## 📚 厳選リソース
- Make Academy（公式無料講座）
- Zapier University
- n8n公式ドキュメント・コミュニティ
