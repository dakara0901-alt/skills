# 🤖 06. API連携

`🤖 01_AI活用・自動化` ｜ `スキル 6 / 100`

> 複数のSaaS/サービスをAPIでつなぎ、データとアクションを自動で流す。

<br>

## 🌍 世界最高峰のツール・手法
- Postman（API検証の定番）
- OpenAPI/Swagger（仕様の標準）
- curl / HTTPie（CLI検証）
- OAuth2 / APIキー（認証設計）

## 🛠 実践ステップ
1. APIドキュメントで認証方式とエンドポイントを把握
2. Postmanで単発リクエストを検証
3. レート制限・ページネーション・エラー処理を実装
4. Webhookで受動連携も設計
5. secrets管理とリトライで堅牢化
