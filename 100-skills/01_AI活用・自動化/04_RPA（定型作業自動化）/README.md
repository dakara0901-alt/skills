# 🤖 04. RPA（定型作業自動化）

`🤖 01_AI活用・自動化` ｜ `スキル 4 / 100`

> 画面操作やファイル処理などPC上の反復作業をロボットで自動実行する。

<br>

## 🌍 世界最高峰のツール・手法
- UiPath（エンタープライズ標準）
- Power Automate Desktop（Windows無料）
- Playwright（ブラウザ自動操作・開発者向け）
- Robocorp / rpaframework（Pythonベース）

## 🛠 実践ステップ
1. 対象業務を録画・観察して手順を分解
2. 例外パターン(ポップアップ等)を洗い出す
3. セレクタ/座標で堅牢に要素を指定
4. 無人実行スケジュールとリトライを設定
5. 月次で対象拡大とメンテ
