# 🤖 07. 音声入力ワークフロー

`🤖 01_AI活用・自動化` ｜ `スキル 7 / 100`

> 音声→文字起こし→AI整形→アウトプットまでを自動化し、思考速度で成果物を作る。

<br>

## 🌍 世界最高峰のツール・手法
- Whisper / whisper.cpp（高精度文字起こし）
- Superwhisper / MacWhisper（Mac常駐入力）
- Deepgram / AssemblyAI（API・話者分離）
- Claude/GPTで整形・要約

## 🛠 実践ステップ
1. 録音/口述デバイスと文字起こしエンジンを選定
2. 話者分離・タイムスタンプの要否を決める
3. 文字起こし→AIで整形するプロンプトを定型化
4. 議事録/記事/タスクへ自動振り分け
5. ショートカット化して即起動
