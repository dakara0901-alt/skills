# 03. AIエージェント構築

> カテゴリ: 🤖 01_AI活用・自動化　｜　スキルNo. 3/100

## 📌 概要
自律的にツールを使って多段タスクをこなすカスタムAIアシスタントを作る。

## 🌍 世界最高峰のツール・手法
- Claude Agent SDK（本番運用向け）
- OpenAI Agents SDK / Assistants
- LangGraph（状態管理・複雑ワークフロー）
- Dify / Flowise（GUIでエージェント構築）

## 🛠 実践ステップ
1. 解決したい業務のゴールと成功指標を定義
2. 必要なツール(検索/DB/API)を洗い出し接続
3. システムプロンプトで役割と手順を設計
4. 評価セットで精度・コスト・レイテンシを測定
5. ガードレールとログを入れて本番投入

- LangGraph公式チュートリアル
- Dify公式ドキュメント
