# 🤖 01. プロンプトエンジニアリング

`🤖 01_AI活用・自動化` ｜ `スキル 1 / 100`

> AIから最大の成果を引き出す指示設計。役割・文脈・制約・出力形式を構造化して伝える技術。

<br>

## 🌍 世界最高峰のツール・手法
- Anthropic Claude（長文・推論に最強）
- OpenAI GPT-5 / o系（汎用・ツール利用）
- Google AI Studio（無料で高速検証）
- PromptHub / LangSmith（プロンプト管理・評価）

## 🛠 実践ステップ
1. 役割(Role)・文脈(Context)・タスク・制約・出力形式の5要素で組む
2. 少数例(Few-shot)で望む出力を実例提示
3. 思考の連鎖(Chain-of-Thought)で推論を明示させる
4. 出力をXML/JSONタグで構造化し後工程で機械処理
5. 評価データで反復改善しテンプレ化
