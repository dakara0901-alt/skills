## 🌍 世界最高峰のツール・手法
- Discord / Slack / LINE公式
- Circle / Discourse
- オンボーディング設計
- 貢献の可視化・報酬

## 🛠 実践ステップ
1. コミュニティの目的と行動規範を定義
2. 参加直後の体験(オンボーディング)を設計
3. 定例イベント・話題提供で活性化
4. コアメンバーを巻き込み自走化
5. 健全性指標(発言/定着)を管理
