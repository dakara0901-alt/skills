# 39. ブランディング戦略設計

> カテゴリ: 📣 04_マーケティング・集客　｜　スキルNo. 39/100

## 📌 概要
選ばれる理由を定義し、認知から愛着までのブランド体験を設計する。

## 🌍 世界最高峰のツール・手法
- ポジショニング設計
- ブランドパーパス/バリュー
- ゴールデンサークル(Why)
- 一貫したトーン&マナー

## 🛠 実践ステップ
1. 市場での独自の立ち位置を定義
2. Why(存在意義)を言語化
3. ターゲットの心の中の位置(認知)を設計
4. 全接点で一貫した体験を提供
5. 時間をかけ資産として蓄積

## 📚 厳選リソース
- 『Start With Why』(Simon Sinek)
- 『Positioning』(Al Ries)
- 『This Is Marketing』(Seth Godin)
