# 40. 競合分析・市場調査

> カテゴリ: 📣 04_マーケティング・集客　｜　スキルNo. 40/100

## 📌 概要
市場と競合を体系的に調べ、勝てるポジションと機会を見つける。

## 🌍 世界最高峰のツール・手法
- SWOT / 4P / ファイブフォース
- Ahrefs / SimilarWeb
- 顧客インタビュー
- レビュー分析(VoC)

## 🛠 実践ステップ
1. 市場規模・成長性・トレンドを把握
2. 競合の強み弱み・戦略を分析
3. 顧客の未解決課題(ギャップ)を発見
4. 自社の勝てる差別化軸を定義
5. 定点観測で変化を追う
