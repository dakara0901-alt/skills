# 24. ロゴ・ブランドキット作成

> カテゴリ: 🎨 03_デザイン・ビジュアル　｜　スキルNo. 24/100

## 📌 概要
一貫したブランド視覚資産(ロゴ/色/フォント/トーン)を体系化する。

## 🌍 世界最高峰のツール・手法
- Figma（デザインシステム)
- Looka / Brandmark（AIロゴ)
- Adobe Illustrator
- カラー理論・タイポグラフィ

## 🛠 実践ステップ
1. ブランドの人格・価値を言語化
2. ロゴ(可変・モノクロ対応)を設計
3. カラーパレット・フォント階層を定義
4. 使用ルール(余白/禁止例)を文書化
5. 全媒体へ一貫適用
