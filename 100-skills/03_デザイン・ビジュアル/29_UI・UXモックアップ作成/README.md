## 📌 概要
アプリ/サイトの画面設計を可視化し、開発前に体験を検証する。

## 🌍 世界最高峰のツール・手法

- Framer（高機能プロトタイプ)

3. コンポーネント・デザインシステム化
4. インタラクティブなプロトタイプで検証
5. ユーザーテストで改善
