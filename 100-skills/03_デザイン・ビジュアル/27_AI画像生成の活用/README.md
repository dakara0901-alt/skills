# 27. AI画像生成の活用

> カテゴリ: 🎨 03_デザイン・ビジュアル　｜　スキルNo. 27/100

## 📌 概要
テキストから高品質画像を生成し、制作コストを劇的に下げる。

## 🌍 世界最高峰のツール・手法
- Midjourney（品質最高峰)
- DALL·E / GPT Image
- Stable Diffusion / ComfyUI（自由度)
- Adobe Firefly（商用安全)

## 🛠 実践ステップ
1. 用途と権利要件(商用可否)を確認
2. 被写体/画風/構図/光をプロンプト化
3. 参照画像・シードで一貫性を出す
4. 反復生成しバリエーション選定
5. 後処理(補正/合成)で仕上げ
