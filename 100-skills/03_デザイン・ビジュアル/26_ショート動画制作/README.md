# 26. ショート動画制作

> カテゴリ: 🎨 03_デザイン・ビジュアル　｜　スキルNo. 26/100

## 📌 概要
TikTok/Reels/Shortsで拡散する縦型短尺動画を企画・制作する。

## 🌍 世界最高峰のツール・手法
- CapCut（テンプレ・トレンド音源)
- フック→展開→ループ設計
- トレンド分析
- 自動字幕・エフェクト

## 🛠 実践ステップ
1. 最初の1秒でフックを作る
2. 1本1メッセージ・15〜30秒
3. トレンド音源・フォーマットに乗る
4. 字幕必須(無音視聴対応)
5. 最後をループさせ再生数を稼ぐ

## 📚 厳選リソース
- CapCut公式
- TikTok Creative Center
- 各プラットフォームのShorts/Reelsガイド
