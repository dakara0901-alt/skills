# 30. 写真加工・レタッチ

> カテゴリ: 🎨 03_デザイン・ビジュアル　｜　スキルNo. 30/100

## 📌 概要
写真を補正・加工し、商品や人物を魅力的に見せる。

## 🌍 世界最高峰のツール・手法
- Adobe Lightroom（現像)
- Photoshop（合成・修復)
- Photopea（無料・ブラウザ)
- AI補正(生成塗りつぶし)

## 🛠 実践ステップ
1. 露出・ホワイトバランスを基礎補正
2. 不要物除去・肌/商品レタッチ
3. 色調で世界観を統一(プリセット)
4. 切り抜き・背景合成
5. 書き出し(用途別解像度)

## 📚 厳選リソース
- Adobe Lightroom公式チュートリアル
- Photopea公式
- PHLEARN(レタッチ教材)
