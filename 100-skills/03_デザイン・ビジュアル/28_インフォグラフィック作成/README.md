# 🎨 28. インフォグラフィック作成

`🎨 03_デザイン・ビジュアル` ｜ `スキル 28 / 100`

> 複雑な情報を図解して直感的に伝え、シェアされるビジュアルを作る。

<br>

## 🌍 世界最高峰のツール・手法
- Canva / Piktochart
- Flourish（データ可視化)
- Figma
- 情報階層・視線誘導

## 🛠 実践ステップ
1. 伝えたい1つの結論を決める
2. データを絞り比較・関係を可視化
3. 視線の流れ(Z/F型)で配置
4. アイコン・色で情報を分類
5. 出典明記と正確性を担保
