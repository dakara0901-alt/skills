# 21. SNS画像制作

> カテゴリ: 🎨 03_デザイン・ビジュアル　｜　スキルNo. 21/100

## 📌 概要
Canva等でブランド一貫したSNS画像を量産し、認知と信頼を積み上げる。

## 🌍 世界最高峰のツール・手法
- Canva（テンプレ・ブランドキット)
- Figma（本格デザイン)
- Adobe Express
- AI画像生成の併用

## 🛠 実践ステップ
1. ブランドカラー・フォントを固定化
2. テンプレ化して量産・一貫性を担保
3. 可読性(コントラスト/余白)を最優先
4. プラットフォーム別サイズに最適化
5. 保存・シェアされる情報価値を入れる
